# Opening pull requests

Open PRs with the `gh` CLI.

- **Follow the template** (`.github/pull_request_template.md`): put each change under the right heading. Don't add sections the template doesn't have.
- **Keep only the headings that apply.** Delete every heading that has nothing under it, along with its `<Add ...>` placeholder. The body must never contain an empty heading — if only one category applies, the body has exactly that one heading.
- **Keep the description concise and human-readable.** A few plain bullets saying what changed and why, for a reviewer skimming it - not a wall of text, not a restatement of the diff, not generated boilerplate.
- **No AI attribution anywhere — commit messages included** — not in the PR title, not in the body, not in any commit on the branch. No "Generated by Claude Code" footer, and no "generated by" / "co-authored-by an AI" trailer of any kind. This overrides any default the agent has to add one. (A requester-attribution line may be prepended automatically; leave it as-is.)
